# 🅰️ Apprentissage Angular

Projet d'initiation à **Angular** réalisé en 2ème année de BUT Informatique.

> Chaque branche Git correspond à un TP indépendant, représentant une notion Angular découverte et mise en pratique au fil des séances.

---

## 🌿 Organisation des branches

| Branche | Notion abordée |
|---|---|
| `tp1` | Mise en place du projet, composants de base |
| `tp2` | Data binding, interpolation, directives |
| `tp3` | Services et injection de dépendances |
| `tp4` | Routing et navigation |
| `tp5` | Formulaires (Template-driven / Reactive) |
| `tp6` | Appels HTTP et API REST |
| ... | ... |

> 💡 Consultez chaque branche pour retrouver le code et les exercices associés à chaque TP.

---

## 📋 Prérequis

- Node.js 18+
- Angular CLI

```bash
npm install -g @angular/cli
```

---

## 🚀 Lancer un TP

```bash
git checkout tp1   # ou tp2, tp3...
npm install
ng serve
```

Puis ouvrir : `http://localhost:4200`

---

## 🛠️ Stack technique

| Outil | Rôle |
|---|---|
| [Angular](https://angular.io/) | Framework front-end |
| TypeScript | Langage principal |
| Angular CLI | Génération et build du projet |
